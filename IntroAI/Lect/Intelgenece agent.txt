Agents

An agent is an entity that perceives and acts

An agent is anything that can be viewed as perceiving its environment through sensors and acting upon that environment through actuators

Human agent: eyes, ears, and other organs for sensors; hands, legs, mouth, and other body parts for actuators

Robotic agent: cameras and infrared range finders for sensors; various motors for actuators

Agents and environments

The agent function maps from percept histories to actions: [f: P* →A]

The agent program runs on the physical architecture to produce f

agent = architecture + program- Percept refers to the agent's perceptual input at a given instant- Percept Sequence is a complete history of percepts.

Rationality

The proposed definition requires:

Information gathering/exploration- To maximize future rewards

Learn from percepts- Extending prior knowledge

Agent autonomy- Compensate for incorrect prior knowledge

Rational agents

Rationality is distinct from omniscience (all- knowing with infinite knowledge)

Agents can perform actions in order to modify future percepts so as to obtain useful information (information gathering, exploration)

An agent is autonomous if its behavior is determined by its own experience (with ability to learn and adapt)

Rational agents

An agent should strive to "do the right thing", based on what it can perceive and the actions it can perform. The right action is the one that will cause the agent to be most successful

Performance measure: An objective criterion for success of an agent's behavior

E.g., performance measure of a vacuum- cleaner agent could be amount of dirt cleaned up, amount of time taken, amount of electricity consumed, amount of noise generated, etc.

Rational agents

Rational Agent: For each possible percept sequence, a rational agent should select an action that is expected to maximize its performance measure, given the evidence provided by the percept sequence and whatever built- in knowledge the agent has.

Environment Types
• Fully Observable: The agent can perceive the complete state of the environment at any given moment. Think of a board game like chess, where all pieces and their positions are visible.

Example: A chess-playing AI that sees the entire board

• Partially Observable: The agent has limited information about the environment. This can be due to sensors with limited range, incomplete data, or hidden aspects. Imagine navigating a maze where you can only see your immediate surroundings.

Example: A self-driving car navigating with cameras and LIDAR, not seeing behind buildings.

Environment Types
• Deterministic: The outcome of an action depends solely on the current state and chosen action. There's no randomness involved.

Example: Solving a math equation, where following the right steps always leads to the correct answer.

• Stochastic: The outcome of an action is partly based on chance or unknown factors, even with the same state and action.

Example: Playing dice, where the outcome depends on a random roll despite choosing to throw the dice

Environment Types

Single-agent: Only one agent operates in the environment. Example: A robot playing chess against a computer program.- Multi-agent: Multiple agents interact and potentially compete or cooperate with each other. Example: A swarm of robots collaborating to build a structure

Environment Types
• Static: The environment remains unchanged while the agent makes decisions and takes actions.

Example: Static: Solving a Sudoku puzzle, where the grid remains constant.

• Dynamic: The environment changes independently of the agent's actions, requiring constant adaptation.

Example: Traffic navigation, where other cars and weather conditions constantly change

Environment Types
• Discrete: The environment has a finite number of distinct states and actions.

Example: Discrete: Playing checkers with a fixed board and limited moves.

• Continuous: The environment has an infinite number of possible states and actions, often represented by real numbers.

Example: Controlling a robot arm with infinite possible positions and joint angles

Environment Types
• Episodic: Each interaction with the environment is self-contained, and past episodes don't directly influence future ones.

Example: Playing a single game of Tetris, where each game starts fresh.

• Sequential: Actions and outcomes in one episode influence decisions in subsequent episodes, requiring the agent to learn over time.

Example: Training a language model on a continuous stream of text, where past conversations inform future responses

Environment types

The simplest environment is- Fully observable, deterministic, episodic, static, discrete and single-agent.- Most real situations are:- Partially observable, stochastic, sequential, dynamic, continuous and multi-agent.

static: rules, a set of condition- action rules

Goal- based agents

[Diagram of a Goal-based agent architecture]

The agent needs a goal to know which situations are desirable.

Things become difficult when long sequences of actions are required to find the goal.

Typically investigated in search and planning research.

Major difference: future is taken into account

Is more flexible since knowledge is represented explicitly and can be manipulated.

Utility- based agents

[Diagram of a Utility-based agent architecture]

Certain goals can be reached in different ways.

Some are better, have a higher utility.

Utility function maps a (sequence of) state(s) onto a real number.

Improves on goals:

Selecting between conflicting goals Select appropriately between several goals based on likelihood of success.

Summary: Intelligent Agents

An agent perceives and acts in an environment, has an architecture, and is implemented by an agent program.- Task environment - PEAS (Performance, Environment, Actuators, Sensors)- The most challenging environments are inaccessible, nondeterministic, dynamic, and continuous.- An ideal agent always chooses the action which maximizes its expected performance, given its percept sequence so far.- An agent program maps from percept to action and updates internal state.- Reflex agents respond immediately to percepts.- simple reflex agents- model-based reflex agents- Goal-based agents act in order to achieve their goal(s).- Utility-based agents maximize their own utility function.- Agents can improve their performance through learning.
